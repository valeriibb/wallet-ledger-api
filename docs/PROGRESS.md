- Повні перевірки після Phase 5: PHPUnit — 116 тестів, 145 793 assertions; PHPStan max — 0 помилок; Pint — 152 файли.
- Додано `outbox_events`, `OutboxWriter` port і PostgreSQL adapter; кожна ledger transaction створює `{type}.completed` event у тій самій database transaction.
- Якщо outbox insert падає, ledger transaction, immutable entries і cached balances відкочуються разом.
- Додано `EventPublisher` і `OutboxRelayStore` ports, logging publisher adapter, PostgreSQL relay з `FOR UPDATE SKIP LOCKED` та Artisan command `outbox:relay`.
- Failed publish збільшує `attempts` і залишає event pending. Delivery має at-least-once semantics; consumers повинні deduplicate за stable event ID.
- Concurrency test: 10 relay processes опублікували 50 pending events без duplicate publication у normal run; усі events отримали `published_at`.
- ADR-0007 фіксує transactional outbox, crash window, at-least-once delivery та відхилені direct publish/distributed transaction alternatives.
- Повні перевірки після кроку 6.1: PHPUnit — 121 тест, 145 826 assertions; PHPStan max — 0 помилок; Pint — 166 файлів.
- Додано owner-scoped CRUD для `webhook_endpoints` через `GET/POST/PATCH/DELETE /v1/webhook-endpoints`; усі операції описані в OpenAPI 3.1.
- Signing secret генерується з 32 random bytes, повертається лише під час create і зберігається через Laravel encryption. List/update responses secret не розкривають.
- `WebhookSigner` створює HMAC-SHA256 над exact payload, timestamp та event ID для перевірки цілісності й захисту від replay.
- `WebhookUrlGuard` дозволяє лише HTTPS без credentials, перевіряє hostname та всі A/AAAA addresses, відхиляє private, reserved, loopback, link-local, metadata і local/internal targets.
- Delivery layer у кроці 6.3 повторно перевірятиме DNS безпосередньо перед HTTP request для захисту від DNS rebinding.
- Повні перевірки після кроку 6.2: PHPUnit — 134 тести, 145 874 assertions; PHPStan max — 0 помилок; Pint — 187 файлів.
- Додано `webhook_deliveries`, `WebhookDeliveryStore` і `WebhookHttpClient` ports, PostgreSQL claim adapter з `SKIP LOCKED` та Laravel HTTP adapter.
- Outbox relay створює delivery лише для active endpoints, підписаних на event type; unique `(endpoint_id, event_id)` забезпечує idempotent scheduling.
- Delivery worker повторно виконує SSRF DNS check, формує exact JSON body та HMAC headers, має processing lease і записує response code.
- Retry schedule: 1 хв, 5 хв, 30 хв, 2 год, 24 год; після п'ятої невдалої спроби delivery переходить у `dead_letter`.
- `POST /v1/webhook-deliveries/{delivery}/replay` owner-scoped і повертає delivery у pending; endpoint описано в OpenAPI 3.1.
- Додано Artisan command `webhooks:deliver`; повні перевірки після кроку 6.3: PHPUnit — 137 тестів, 145 892 assertions; PHPStan max — 0 помилок; Pint — 201 файл.
